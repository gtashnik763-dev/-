КАК ПОЛУЧИТЬ APK БЕЗ ANDROID STUDIO:
1. Создать ПУСТОЙ GitHub репозиторий.
2. Загрузить в него СОДЕРЖИМОЕ этой папки, обязательно вместе с папкой .github/workflows.
3. Открыть вкладку Actions -> Build Virazh PPO APK -> Run workflow.
4. Дождаться сборки и скачать Virazh-PPO-APK из Artifacts.
5. Внутри архива будет app-debug.apk, который можно установить на Android.

Примечания:
- Карта использует внешние JS/CSS и тайлы: интернет для многих функций необходим.
- APK в этой среде не скомпилирован и не протестирован на устройстве.
- Некоторые функции браузера (например скачивание data: PNG) могут потребовать отдельной адаптации WebView.
- Это минимальная WebView оболочка, без Google Play публикации.
